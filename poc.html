Report criteria: the strongest finding is a .apk whose extension disappears while the equally long .txt keeps its extension. If both disappear, describe it as a general long-filename truncation, not a Unicode-specific one. Capture the Chrome version, device model, and a screen recording of the Downloads screen.

The RLO test is a negative control: current Chromium replaces Unicode [:Cf:] characters (including U+202E) with _ in net::GenerateFileName, so it should download as invoice_fdp.exe. If it visually shows invoiceexe.pdf, that is a separate, more serious bug.
